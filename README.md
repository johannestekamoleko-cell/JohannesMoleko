# JohannesMoleko

Personal portfolio / CV site — a single static page, no build step.

`index.html` contains the markup and all styles. Open it directly in a browser, or serve locally:

```bash
python3 -m http.server 8000
# http://localhost:8000
```

Because the page is named `index.html`, it is served at the site root when GitHub Pages is enabled
(Settings → Pages → Deploy from branch → `main` / root).
